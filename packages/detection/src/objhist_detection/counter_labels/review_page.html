Counter box review

How to review
  • Every kitchen object of a listed class needs exactly one box with the right class.
  • For each numbered box: pick the correct class and Keep it if it tightly encloses the visible part of one object; otherwise Reject it (background, only part of what is visible, duplicate, or not a listed class).
  • Box what you can see. Parts seen through clear or tinted glass count as visible; parts hidden behind or inside something opaque (a ceramic mug, under the plate) are left out.
  • If a box is close but loose or cut off, point at its outline on the photo: the pointer turns into a resize arrow, and dragging moves that edge (or both edges at a corner). This keeps the box and marks it adjusted. Rejected (dashed) boxes cannot be resized. Reset box undoes the change; Type edges sets the edges in pixels. Zoom is optional, for thin cutlery.
  • If an object has no good box, choose its class under "New box class" and drag a box around it on the photo.
  • Leave objects that are not cup, fork, glass, knife, plate or spoon unboxed.
  • When every object is boxed, press All objects boxed: mark done. Only done photos are exported.
  • Progress is saved in this browser. Download reviews.json into the work folder; regenerating the page loads it again.
